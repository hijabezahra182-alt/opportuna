# OPPORTUNA — Student Opportunity Hub

**Discover. Apply. Grow.**

OPPORTUNA is a modern student opportunity discovery platform designed to help students find scholarships, internships, fellowships, competitions, and other growth opportunities in one organized place.

The project focuses on creating a clean, responsive, and interactive experience rather than a simple static webpage.

## ⚙️ How It Works

### Search

Users can search opportunities using keywords such as:

* Scholarship
* Internship
* AI
* Remote
* Europe
* Fellowship

The search checks opportunity titles, organizations, categories, locations, and opportunity types.

### Filters

Users can quickly filter opportunities by:

* All
* Scholarships
* Internships
* Fellowships
* Competitions

### Save Opportunities

Clicking the heart icon saves an opportunity.

Saved opportunities are stored using **LocalStorage**, meaning they remain available after refreshing the page.
